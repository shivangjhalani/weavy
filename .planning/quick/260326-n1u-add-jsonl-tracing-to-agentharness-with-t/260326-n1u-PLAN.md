**harness.py changes:**

1. Add `from lifeos.agent.tracer import Tracer` (base class only — never JsonlTracer).
2. Add `tracer: Tracer | None = None` and `thinking_config: types.ThinkingConfig | None = None` params to __init__. Store as self.tracer and self.thinking_config.
3. In run(), if self.thinking_config is set, add it to the GenerateContentConfig: `thinking_config=self.thinking_config`.
4. Add tracer calls at these points:

   - **run_start**: Before the while loop — `self.tracer.on_run_start(self.model, list(self.tools.keys()), datetime.now(timezone.utc).isoformat())`. Import datetime/timezone at top.
   - **llm_response**: After getting response and extracting candidate, before appending to contents — extract thinking text from candidate.content.parts (parts where `hasattr(p, 'thought') and p.thought` is True have text that is thinking), get finish_reason, count fc_parts. Call `self.tracer.on_llm_response(turn, str(finish_reason), len(fc_parts), thinking_text, response_text)`. Track `turn` as a counter starting at 1, incrementing each iteration.
   - **llm_error**: In the two RuntimeError cases (no candidates, None content) — call `self.tracer.on_llm_error(turn, "no_candidates"/"none_content", str(finish_reason))` before raising.
   - **tool_call**: Inside the fc_parts dispatch loop, before calling the tool — `self.tracer.on_tool_call(turn, fc.name, dict(fc.args))`.
   - **tool_result / tool_error**: Wrap each tool dispatch in try/except. On success: measure duration_ms with time.perf_counter(), call `self.tracer.on_tool_result(turn, fc.name, result, duration_ms, True)`. On exception: call `self.tracer.on_tool_error(turn, fc.name, str(e))`, then re-raise.
   - **run_end**: Before the `return response.text` — `self.tracer.on_run_end(turn, total_tool_calls, response.text)`. Track total_tool_calls as a running sum of len(fc_parts) across turns.

   All tracer calls are guarded: `if self.tracer:` before each call. When tracer is None (default), zero overhead — no function calls, no conditionals beyond the None check.
