  <action>
    Create `lifeos/memory/graph.py` with the following functions:

    1. `init_graph(host, port, graph_name) -> graph`:
       - `db = FalkorDB(host=host, port=port)`
       - `graph = db.select_graph(graph_name)`
       - Create range indexes: `CREATE INDEX FOR (n:Node) ON (n.name)`, `CREATE INDEX FOR (n:Node) ON (n.type)`, `CREATE INDEX FOR (n:Node) ON (n.transcript_id)`, `CREATE INDEX FOR (n:Node) ON (n.aliases)`
       - Create vector index: `CREATE VECTOR INDEX FOR (n:Node) ON (n.embedding) OPTIONS {dimension:3072, similarityFunction:'cosine'}`
       - Wrap each CREATE INDEX in try/except to handle "index already exists" gracefully
       - Return graph

    2. `create_node(graph, node: Node) -> None`:
       - Call `embed_text(node.summary)` to get embedding
       - Run Cypher: `CREATE (n:Node {id: $id, name: $name, type: $type, summary: $summary, aliases: $aliases, embedding: vecf32($embedding), log: $log_json, refs: $refs_json, created_at: $ts, updated_at: $ts})`
       - Where `$name` is `node.aliases[0] if node.aliases else node.id`, `$log_json` and `$refs_json` are JSON-serialized strings of the lists, `$ts` is UTC ISO timestamp
       - Note: FalkorDB stores properties as primitives or arrays of primitives. Complex nested objects (log entries, refs) must be stored as JSON strings and deserialized on read.

    3. `update_node(graph, node_id: str, new_summary: str, log_entry: str, transcript_ref: dict | None = None) -> None`:
       - Call `embed_text(new_summary)` — always re-embed per GRPH-05
       - Cypher: `MATCH (n:Node {id: $id}) SET n.summary = $summary, n.embedding = vecf32($embedding), n.updated_at = $ts`
       - Append to log: read existing n.log JSON string, parse, append new LogEntry, serialize back, SET n.log

    4. `create_edge(graph, edge: Edge) -> None`:
       - Call `embed_text(edge.summary)` to get embedding
       - Cypher: `MATCH (s:Node {id: $source_id}), (t:Node {id: $target_id}) CREATE (s)-[r:EDGE {id: $id, type: $type, summary: $summary, embedding: vecf32($embedding), log: $log_json, refs: $refs_json, created_at: $ts, updated_at: $ts}]->(t)`

    5. `update_edge(graph, edge_id: str, new_summary: str, log_entry: str) -> None`:
       - Call `embed_text(new_summary)` — always re-embed per GRPH-05
       - Cypher: `MATCH ()-[r:EDGE {id: $id}]->() SET r.summary = $summary, r.embedding = vecf32($embedding), r.updated_at = $ts`
       - Append to log same pattern as update_node

    6. `vector_search(graph, query_text: str, k: int = 5) -> list[tuple[str, str, float]]`:
       - Call `embed_query(query_text)` to get query embedding
       - Cypher: `CALL db.idx.vector.queryNodes('Node', 'embedding', $k, vecf32($embedding)) YIELD node, score RETURN node.id, node.summary, score ORDER BY score DESC`
       - Return list of (id, summary, score) tuples

    7. Helper `get_node(graph, node_id: str) -> dict | None`:
       - Cypher: `MATCH (n:Node {id: $id}) RETURN n`
       - Return node properties as dict or None if not found
