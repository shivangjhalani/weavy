    **graph.py changes:**

    1. **init_graph**: Remove the index `CREATE INDEX FOR (n:Node) ON (n.type)`. Add index `CREATE INDEX FOR ()-[r:EDGE]->() ON (r.label)`. Keep all other indexes (n.name, n.aliases, n.transcript_id, vector index).

    2. **create_node**: Remove `type: $type` from the CREATE Cypher. The `name` field is now taken from `node.name` (not derived from aliases). Remove `"type": node.type` from the params dict. Use `"name": node.name` in params.

    3. **create_edge**: Replace `type: $type` with `label: $label` in the CREATE Cypher. Replace `"type": edge.type` with `"label": edge.label` in params dict.

    4. **update_node**: Extend signature to:
       ```python
       def update_node(
           graph,
           node_id: str,
           new_summary: str,
           log_entry: str,
           transcript_ref: dict | None = None,
           new_aliases: list[str] | None = None,
           new_refs: list[TranscriptRef] | None = None,
           new_name: str | None = None,
           recorded_at: datetime | None = None,
       ) -> None:
       ```
       - When `new_aliases` is provided: read existing aliases, extend with new ones (union, no duplicates), SET n.aliases in the update query.
       - When `new_refs` is provided: read existing refs JSON, append new refs, serialize back.
       - When `new_name` is provided: SET n.name = $new_name in the update query.
       - When `recorded_at` is provided: use it for the LogEntry timestamp instead of `datetime.now(timezone.utc)`.
       - The Cypher SET clause must be dynamically built based on which optional params are provided.

    5. **update_edge**: Extend signature to:
       ```python
       def update_edge(
           graph,
           edge_id: str,
           new_summary: str,
           log_entry: str,
           new_refs: list[TranscriptRef] | None = None,
           recorded_at: datetime | None = None,
       ) -> None:
       ```
       - When `new_refs` is provided: read existing refs JSON, append new refs, serialize back, SET r.refs in query.
       - When `recorded_at` is provided: use it for the LogEntry timestamp.

    6. **Add delete_node**:
       ```python
       def delete_node(graph, node_id: str) -> None:
           graph.query("MATCH (n:Node {id: $id}) DETACH DELETE n", {"id": node_id})
       ```

    7. **Add delete_edge**:
       ```python
       def delete_edge(graph, edge_id: str) -> None:
           graph.query("MATCH ()-[r:EDGE {id: $id}]->() DELETE r", {"id": edge_id})
       ```

    8. **Add search_nodes_by_alias**:
       ```python
       def search_nodes_by_alias(graph, alias: str) -> list[dict]:
           result = graph.query(
               "MATCH (n:Node) WHERE $alias IN n.aliases "
               "RETURN n.id, n.name, n.aliases, n.summary",
               {"alias": alias},
           )
           return [
               {"id": row[0], "name": row[1], "aliases": row[2], "summary": row[3]}
               for row in result.result_set
           ]
       ```

    9. **Add set_node_log** (for compression pass — Pitfall 6: does NOT re-embed):
       ```python
       def set_node_log(graph, node_id: str, log_entries: list[dict]) -> None:
           log_json = json.dumps(log_entries, default=str)
           graph.query(
               "MATCH (n:Node {id: $id}) SET n.log = $log_json, n.updated_at = $ts",
               {"id": node_id, "log_json": log_json, "ts": datetime.now(timezone.utc).isoformat()},
           )
       ```

    10. **Add set_edge_log** (same pattern for edges):
        ```python
        def set_edge_log(graph, edge_id: str, log_entries: list[dict]) -> None:
            log_json = json.dumps(log_entries, default=str)
            graph.query(
                "MATCH ()-[r:EDGE {id: $id}]->() SET r.log = $log_json, r.updated_at = $ts",
                {"id": edge_id, "log_json": log_json, "ts": datetime.now(timezone.utc).isoformat()},
            )
        ```
