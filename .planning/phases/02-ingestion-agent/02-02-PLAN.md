  <action>
    **Create lifeos/agent/tools.py:**

    ```python
    import uuid
    import json
    from datetime import datetime, timezone

    from google.genai import types

    from lifeos.memory import graph as graph_module
    from lifeos.memory.models import Node, Edge, TranscriptRef, LogEntry, EpisodeSpan
    from lifeos.memory.store import TranscriptStore
    from lifeos.core.embeddings import embed_text
    ```

    Implement `build_tools(graph, store: TranscriptStore, recording_timestamp: datetime | None = None) -> tuple[dict, list]`:

    The `recording_timestamp` param is passed through to tools that create log entries so they use the recording time, not current time.

    **9 tool implementations (all closures inside build_tools):**

    1. `search_nodes_by_alias(alias: str) -> dict` — calls `graph_module.search_nodes_by_alias(graph, alias)`, returns `{"matches": results, "count": len(results)}`.

    2. `search_nodes_by_embedding(query: str, k: int = 5) -> dict` — calls `graph_module.vector_search(graph, query, k=k)`, returns `{"matches": [{"node_id": r[0], "summary": r[1], "score": r[2]} for r in results]}`.

    3. `create_node(name: str, summary: str, aliases: list[str] | None = None, log_note: str | None = None, transcript_id: str | None = None, start_offset: int | None = None, end_offset: int | None = None) -> dict` — generates `node_id = str(uuid.uuid4())`, builds aliases list (default `[name]` if not provided), builds refs list from transcript_id/offsets if provided, builds initial log entry from log_note with recording_timestamp, creates `Node(...)`, calls `graph_module.create_node(graph, node)`, returns `{"node_id": node_id, "created": True}`.

    4. `update_node(node_id: str, summary: str, log_note: str, new_aliases: list[str] | None = None, transcript_id: str | None = None, start_offset: int | None = None, end_offset: int | None = None) -> dict` — builds new_refs from transcript_id/offsets if provided, calls `graph_module.update_node(graph, node_id, summary, log_note, new_aliases=new_aliases, new_refs=new_refs, recorded_at=recording_timestamp)`, returns `{"node_id": node_id, "updated": True}`.

    5. `delete_node(node_id: str) -> dict` — calls `graph_module.delete_node(graph, node_id)`, returns `{"node_id": node_id, "deleted": True}`.

    6. `create_edge(source_id: str, target_id: str, label: str, summary: str, log_note: str | None = None, transcript_id: str | None = None, start_offset: int | None = None, end_offset: int | None = None) -> dict` — generates edge_id, builds refs/log, creates `Edge(...)`, calls `graph_module.create_edge(graph, edge)`, returns `{"edge_id": edge_id, "created": True}`.

    7. `update_edge(edge_id: str, summary: str, log_note: str, transcript_id: str | None = None, start_offset: int | None = None, end_offset: int | None = None) -> dict` — builds new_refs, calls `graph_module.update_edge(...)`, returns `{"edge_id": edge_id, "updated": True}`.

    8. `delete_edge(edge_id: str) -> dict` — calls `graph_module.delete_edge(graph, edge_id)`, returns `{"edge_id": edge_id, "deleted": True}`.

    9. `create_episode_spans(transcript_id: str, spans: list[dict]) -> dict` — loads transcript via `store.load(transcript_id)`, for each span dict (keys: start_offset, end_offset, summary), creates `EpisodeSpan(...)` with `embedding=embed_text(span["summary"])`, appends to transcript data's `episode_spans` list, saves transcript back via `store.save(transcript_id, data)`, returns `{"transcript_id": transcript_id, "spans_created": len(spans)}`.

    **FunctionDeclarations (9 total):**

    Build using `types.FunctionDeclaration(name=..., description=..., parameters=types.Schema(...))` per the verified pattern in RESEARCH.md. Each declaration mirrors the tool's parameters exactly.

    Key declarations (all use `types.Schema`):
    - `search_nodes_by_alias`: param `alias` (STRING, required)
    - `search_nodes_by_embedding`: params `query` (STRING, required), `k` (INTEGER, optional)
    - `create_node`: params `name` (STRING, required), `summary` (STRING, required), `aliases` (ARRAY of STRING, optional), `log_note` (STRING, optional), `transcript_id` (STRING, optional), `start_offset` (INTEGER, optional), `end_offset` (INTEGER, optional)
    - `update_node`: params `node_id` (STRING, required), `summary` (STRING, required), `log_note` (STRING, required), `new_aliases` (ARRAY of STRING, optional), `transcript_id`/`start_offset`/`end_offset` (optional)
    - `delete_node`: param `node_id` (STRING, required)
    - `create_edge`: params `source_id` (STRING, required), `target_id` (STRING, required), `label` (STRING, required), `summary` (STRING, required), `log_note` (STRING, optional), `transcript_id`/`start_offset`/`end_offset` (optional)
    - `update_edge`: params `edge_id` (STRING, required), `summary` (STRING, required), `log_note` (STRING, required), `transcript_id`/`start_offset`/`end_offset` (optional)
    - `delete_edge`: param `edge_id` (STRING, required)
    - `create_episode_spans`: params `transcript_id` (STRING, required), `spans` (ARRAY of OBJECT with start_offset/end_offset/summary, required)

    Return `(tools_dict, declarations_list)` where tools_dict maps name string to callable.
